# pintam2

Primera base de la aplicación PintaM² desarrollada en Flutter.

## Primer objetivo

Construir la pantalla de Inicio y luego conectar:

1. Clientes
2. Obras
3. Nuevo presupuesto
4. Medidas
5. Trabajos
6. Materiales
7. Resumen
8. PDF

## Ejecutar

Con Flutter instalado:

```bash
flutter pub get
flutter run
```

Para Android:

```bash
flutter run
```

Para Windows:

```bash
flutter run -d windows
```

Para iOS se requiere macOS + Xcode:

```bash
flutter run -d ios
```
